MultiChain Journal 隱私權政策

最後更新日期：2026 年 2 月 26 日

1. 概述

MultiChain Journal（以下簡稱「本應用」）是一款唯讀的加密貨幣資產追蹤與記帳工具。我們非常重視您的隱私。本隱私權政策說明本應用如何處理您的資料。

2. 資料收集

本應用不會收集、傳輸或儲存任何個人資料至外部伺服器。

所有資料（包括錢包地址、交易所 API 金鑰、交易記錄）均儲存在您的裝置本地，使用 AES-256 加密保護。

3. 第三方 API 存取

本應用會連接以下第三方服務以查詢公開的區塊鏈資料：

  • CoinGecko API — 查詢加密貨幣價格（僅公開市場資料）
  • Etherscan / Polygonscan / BscScan — 查詢區塊鏈交易歷史（僅公開地址查詢）
  • Moralis API — 多鏈資料聚合（僅公開地址查詢）
  • Binance / Bybit API — 查詢交易所餘額（使用您提供的唯讀 API 金鑰）

這些 API 呼叫均使用 HTTPS 加密傳輸，僅傳送查詢所需的最少資訊（公開地址或唯讀 API 金鑰）。

4. 資料儲存與安全

  • 所有敏感資料使用 AES-256 加密儲存於裝置本地
  • API 金鑰儲存於 iOS Keychain / Android Keystore
  • 支援 Face ID / Touch ID 生物辨識認證
  • PIN 碼使用 PBKDF2 加鹽雜湊保護
  • 暴力破解自動鎖定機制

5. 資料刪除

您可以隨時在應用設定中選擇「清除所有資料」來刪除所有本地儲存的資料。解除安裝應用同樣會移除所有資料。

6. 兒童隱私

本應用不針對 18 歲以下的使用者，也不會有意收集任何未成年人的資料。

7. 政策變更

我們可能會不定期更新本隱私權政策。任何變更都會在本頁面上公布。

MultiChain Journal Privacy Policy

Last updated: February 26, 2026

1. Overview

MultiChain Journal ("the App") is a read-only cryptocurrency portfolio tracker and accounting tool. We take your privacy seriously. This privacy policy explains how the App handles your data.

2. Data Collection

This App does not collect, transmit, or store any personal data to external servers.

All data (including wallet addresses, exchange API keys, transaction records) is stored locally on your device, protected with AES-256 encryption.

3. Third-Party API Access

The App connects to the following third-party services to query public blockchain data:

  • CoinGecko API — Cryptocurrency price queries (public market data only)
  • Etherscan / Polygonscan / BscScan — Blockchain transaction history (public address queries only)
  • Moralis API — Multi-chain data aggregation (public address queries only)
  • Binance / Bybit API — Exchange balance queries (using your read-only API keys)

All API calls use HTTPS encryption and transmit only the minimum information required (public addresses or read-only API keys).

4. Data Storage & Security

  • All sensitive data stored locally with AES-256 encryption
  • API keys stored in iOS Keychain / Android Keystore
  • Face ID / Touch ID biometric authentication
  • PIN protected with PBKDF2 salted hashing
  • Automatic brute-force lockout mechanism

5. Data Deletion

You can delete all locally stored data at any time via the "Clear All Data" option in Settings. Uninstalling the App also removes all data.

6. Children's Privacy

This App is not intended for users under 18 years of age and does not knowingly collect data from minors.

7. Policy Changes

We may update this privacy policy from time to time. Any changes will be posted on this page.
