# 更新日誌 (Changelog)

所有重要更改都會記錄在此文件中。

格式基於 [Keep a Changelog](https://keepachangelog.com/zh-TW/1.0.0/)，
版本號遵循 [Semantic Versioning](https://semver.org/lang/zh-TW/)。

## [2.0.0] - 2025-09-28

### ✨ 新增功能
- **Web 監控介面增強**
  - 新增貸款剩餘天數顯示欄位
  - 餘額分類顯示（閒置/掛單中/已執行）
  - WebSocket 即時數據推送
  - 響應式設計優化

- **VAR 貸款完整支援**
  - 支援浮動利率（Variable Rate）貸款
  - FRR + Delta 動態計算
  - 正確的加權平均利率計算

- **高利率自動響應系統**
  - 多層級利率響應策略（標準/中高/高/非常高/極端）
  - Spike 檢測（高於平均 50%）
  - 動態期限調整
  - 緊急通知（APR > 20%）

### 🔧 修復
- 修復 VAR 貸款利率顯示問題（之前顯示 0.30%）
- 修正平均利率計算使用加權平均值
- 修復可用餘額計算（扣除待結算利息）
- 修正資金分配邏輯（考慮保留金）

### 📈 改進
- 優化資金管理策略（10% 保留金）
- 改進錯誤處理機制
- 增強日誌記錄詳細度
- 提升 WebSocket 連接穩定性

### 📚 文檔
- 新增完整操作指南 (OPERATION_GUIDE.md)
- 更新部署指南 (DEPLOYMENT.md)
- 更新配置範例 (config.example.yaml)
- 改進 README 說明
