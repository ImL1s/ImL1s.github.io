## 🔧 主要修復內容

### 1. HTTP 請求修復
- **問題**: `internal/client/bitfinex.go` 中 HTTP 請求沒有正確包含請求體
- **修復**:
  - 第502行：使用 `bytes.NewReader(bodyBytes)` 包含請求體
  - 第519行：使用 `io.ReadAll(resp.Body)` 正確讀取響應
  - 第547行：同樣修復公共 API 請求的響應讀取

### 2. 策略註冊修復
- **問題**: 混合策略中缺少 `frr_delta` 和 `top_book` 別名支持
- **修復**: 在 `internal/strategy/hybrid.go` 中添加別名支持
  - `case "frr_delta_variable", "frr_delta"`
  - `case "top_book_undercut", "top_book"`

### 3. 配置一致性修復
- **問題**: `.env` 文件設定為 `frr_delta`，但應該使用 `hybrid`
- **修復**: 更新 `.env` 中 `BFX_STRATEGY_TYPE=hybrid`
