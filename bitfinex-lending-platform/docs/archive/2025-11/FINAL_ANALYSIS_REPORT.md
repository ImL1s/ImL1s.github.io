## 🚨 問題優先級（最終版）

### P0: 可用餘額不足問題 🔴
**問題描述**：
- 監控顯示可用餘額：**$46.40**
- 低於 $50 內部最小限制
- 遠低於 Bitfinex $150 官方要求
- **後果**：觸發最小限制，完全無法交易

**可能原因**：
- 資金幾乎全部在放貸中（$3,513.13）
- 可用餘額僅 $46.40，無法開新單
- 需要等待部分貸款到期釋放資金

### P1: 最小金額設定錯誤 🟠
**官方要求 vs 實際設定**：
| 項目 | Bitfinex 官方 | 機器人設定 | 建議值 |
|------|--------------|-----------|--------|
| 單筆最小放貸 | $150 | $50 | **$150** |
| 最小借款 | $175 | N/A | N/A |

## 💡 解決方案路線圖

### 第一階段：修復執行層 BUG（1-2 天）
1. **修復餘額計算**
   - 檢查 API wallet balance 解析邏輯
   - 確認 index 4 對應的是 available balance
   - 修復浮點數解析問題

2. **調整最小金額**
   ```go
   // absoluteMinimum := 50.0  // 舊值
   absoluteMinimum := 150.0     // 新值（符合 Bitfinex 要求）
   ```

3. **啟用風險管理**
   - 取消註解 `ApplyLimits`
   - 調整過濾邏輯避免過度限制

### 第二階段：策略優化（3-5 天）
1. **切換到 Hybrid 策略**
   ```yaml
   strategy:
     type: "hybrid"  # 從 "grid" 改為 "hybrid"
   ```

2. **優化 Grid 參數**
   - distribution: "logarithmic"
   - min_rate: FRR * 0.8
   - rebalance_interval: 180

3. **實現事件驅動 Rebalance**
   - 市場利率大幅變動時觸發
   - 訂單簿頂部被搶時觸發

### 第三階段：長期優化（2-4 週）
1. **完善 Analytics 模組**
   - 實現 predictor.go
   - 實現 history.go
   - 加入機器學習預測

2. **增強 Web UI**
   - 歷史 APR 圖表
   - 手動操作功能
   - 策略熱重載

3. **建立回測系統**
   - 歷史數據驗證
   - 策略優化測試
