## 🔧 核心模組設計

### 1. Bot Engine (機器人引擎)

**職責：**
- 協調所有子系統
- 管理生命週期
- 處理異常情況

**關鍵組件：**
```go
type Bot struct {
    config      *Config
    client      *BitfinexClient
    strategy    Strategy
    riskManager *RiskManager
    metrics     *Metrics
}
```

### 2. Strategy System (策略系統)

**策略介面：**
```go
type Strategy interface {
    CalculateOffers(balance float64, market *MarketData) []Offer
    ShouldRebalance(offers map[string]Offer) bool
    UpdateOrderBook(update OrderBookUpdate)
}
```

**策略實作：**

#### Grid Strategy (網格策略)
- 將資金分散到多個價格層級
- 支援線性、指數、對數分布
- 動態調整網格範圍

#### Adaptive Strategy (自適應策略)
- 基於機器學習優化
- 即時市場分析
- 自動參數調整

#### FRR Strategy (FRR策略)
- 追蹤 Flash Return Rate
- 支援 FRR Delta 設定
- 智能期限管理

### 3. Risk Management (風險管理)

**風險評估模型：**
```
總風險分數 = w1×市場風險 + w2×集中度風險 + w3×流動性風險 + w4×交易對手風險

其中：
- w1 = 0.35 (市場風險權重)
- w2 = 0.25 (集中度風險權重)
- w3 = 0.25 (流動性風險權重)
- w4 = 0.15 (交易對手風險權重)
```

**風險控制措施：**
1. **曝險限制**: 最大 90% 資金可供放貸
2. **單筆限制**: 單筆訂單不超過總資金 20%
3. **集中度控制**: 防止資金過度集中
4. **緊急停損**: 損失超過閾值自動停止

- bfx-signature: 簽名
