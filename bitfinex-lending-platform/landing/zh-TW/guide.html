操作指南

關於設定並執行 Bitfinex 自動借貸策略，您需要知道的一切都在這裡。

1. 連結您的 Bitfinex 帳號

為了讓機器人可以自動幫您放貸，您必須提供您的 Bitfinex API 金鑰。我們使用這些金鑰僅限於執行放貸操作。

必要的 API 權限

為了您的安全，在 Bitfinex 建立 API 金鑰時，您應該只開啟最少必須的權限：

  • 保證金資金 (Margin Funding): 讀取與寫入 (必要，用來掛單與取消放貸訂單)
  • 錢包 (Wallets): 讀取 (必要，用來檢查您可用的放貸餘額)

安全提示： 請確保絕對不要開啟任何提款 (Withdrawal) 或是交易 (Trading) 權限。機器人不需要這些權限，也無法動用您的資金。

2. 了解放貸策略

借貸機器人支援多種智慧策略，專為不同的市場狀況設計。您可以隨時在 App 中切換它們。

FRR (閃電回報率)

一個動態利率，取決於當前活躍的固定利率資金合約的平均值。機器人會以略高或略低於此利率放貸，以確保跟隨市場趨勢並最大化您的資金利用率。

網格策略 (Grid Strategy)

網格策略會將您可用的本金切分為多個區塊，並將它們掛在階梯式的利率上 (例如 10%、15%、20%)。如果市場利率暫時飆升，您較高層級的區塊將被成交，捕捉到極高的收益。

自適應 AI (Premium)

我們獨家的機器學習模型，能夠預測短期的利率變動，並在市場飆升前自動調整您的放貸利率。

3. 管理您的資金

一旦機器人啟動，它將持續監控您的 Bitfinex funding 錢包。

最低放貸金額

Bitfinex 對於掛出放貸訂單有嚴格的最低金額限制。如果您可用的餘額低於這個門檻，機器人將無法替您掛單：

  • USD: 最低 $50.00
  • USDT: 最低 50.00 USDT

自動複利 (Auto-Compounding)

預設情況下，Bitfinex 借貸機器人完全支援自動複利。當借款人歸還本金與利息時，機器人會立即偵測到新釋出的可用餘額，並將其全數投入下一次的放貸循環中。

4. 常見問題排除

為什麼我目前的有效連線數量 (Session) 是 0？

請檢查您的 API 金鑰是否正確且未過期。Bitfinex API 金鑰可能會根據您的安全設定需要定期重新展期 (Renew)。

為什麼我的資金一直停留在「可用餘額」沒有借出？

這種情況通常發生在您要求的放貸利率遠高於當前市場的成交利率，或是您的可用餘額低於最低要求的 $50 門檻。
