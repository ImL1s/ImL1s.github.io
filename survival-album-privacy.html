2. 本機資料

為提供整理與提醒功能，本 App 會在 App 私有儲存空間保存：

  • 您拍攝或主動選取的照片副本；
  • 裝置端辨識產生的 OCR 文字、條碼、影像標籤、分類與信心度；
  • 您輸入的標題、備註、收藏狀態與提醒時間；
  • 雲端功能開關與其他 App 偏好設定。

核心整理、搜尋、分類及本機提醒可離線使用。開發者目前沒有一個集中式伺服器接收上述本機相簿資料。

4. 第三方服務與資料傳輸

4.1 Google ML Kit（核心裝置端辨識）

本 App 使用 Google ML Kit 的文字辨識、條碼掃描及影像標籤 SDK。照片與辨識結果由這些 SDK 在裝置上處理，不會為了 ML Kit 推論而上傳照片內容；但 ML Kit SDK 可能依 Google 的說明傳送技術性裝置、使用及診斷資訊。詳見 ML Kit Android Data Disclosure 與 ML Kit Terms。

4.2 Gemini 輔助分類（選用、預設關閉）

只有在您同意雲端功能、啟用 Gemini 並提供自己的 API key 後，本機分類信心不足時，完整照片、可能的 OCR 提示文字與分類提示詞才會送往 Google Gemini API，以取得分類、短標題與摘要建議。API key 保存在裝置安全儲存空間，並透過 HTTPS 傳送給 Google。資料後續處理受您使用的 Google 服務條款及隱私政策規範。

4.3 Supabase 單向雲端副本（選用、預設關閉）

只有在您同意雲端功能、啟用同步並提供自己的 Supabase 專案 URL 與 key 後，本 App 才會將照片副本，以及標題、分類、OCR 文字、影像標籤、條碼、備註、座標（若有）、收藏狀態、建立時間、匿名工作階段識別碼、遠端物件識別／儲存路徑與同步更新時間，上傳到您的 Supabase 專案。App 會使用匿名驗證工作階段；工作階段資料與 key 保存在裝置安全儲存空間。遠端資料的地區、保留、存取權限、費用與刪除由您的 Supabase 專案設定決定。

重要：這是單向雲端副本。本機刪除不會自動刪除既有遠端副本，本 App 目前也不提供從雲端還原。請直接到您的 Supabase 專案管理或刪除遠端內容。

5. 分析、廣告與付款

目前版本沒有整合 Firebase Analytics、Google Analytics、Firebase Crashlytics、廣告 SDK、Google Play Billing 或其他開發者營運的遠端行為分析服務。本 App 內部的事件介面目前不會把事件上傳到開發者伺服器。

若未來新增任何遠端分析、廣告或付費功能，我們會先更新本政策、App 內說明與商店 Data Safety 聲明，再依適用規定提供必要的選擇。

6. 保留與刪除

  • 本機項目：保留到您在 App 內刪除該項目為止。刪除照片項目時，App 會一併移除其本機資料與相關提醒。
  • 解除安裝：Android 會清除 App 私有儲存空間；本 App 已停用 Android 備份。已存在於您個人 Supabase 專案的副本不會因解除安裝而自動刪除。
  • Gemini 與 Supabase：第三方收到的資料依您的第三方帳戶、專案設定及其政策保留。請使用相應服務的管理工具提出存取或刪除要求。

7. 安全措施

本 App 使用 App 私有目錄保存照片與資料庫，並停用 Android 系統備份。Gemini API key、Supabase key 與雲端工作階段使用裝置安全儲存介面保存。Gemini 使用固定的 HTTPS 端點；使用者輸入的 Supabase 位址必須是有效 HTTPS origin 才會接受。

任何系統都無法保證絕對安全。您應妥善保管裝置解鎖資訊、第三方 API key 與 Supabase 專案權限，並定期檢查遠端專案的 RLS 與存取設定。
