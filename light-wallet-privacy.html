Overview

Light Wallet is a non-custodial, multi-chain cryptocurrency wallet application for Android, iOS, and desktop platforms. We are committed to protecting your privacy and ensuring the security of your sensitive data.

This privacy policy describes how CB Studio ("we", "us", or "our") collects, uses, and shares information when you use the Light Wallet application ("App").

What We Never Collect

🔑

Private keys or seed phrases

💰

Wallet balances or addresses

📝

Transaction details

🔐

Passwords or PINs

👤

Personal information (name, email, phone)

📍

Location data

Information We May Collect

We use Firebase Crashlytics and Firebase Analytics to help improve app stability and user experience:

  • Crash Data: Anonymous crash reports including device model, OS version, and stack traces. This data is not linked to your identity.
  • Usage Analytics: Anonymous interaction data such as screen views and feature usage patterns. No personal or financial data is included.
  • Device Information: Device type, operating system version, and app version for diagnostic purposes.
  • Push Notification Token: A device token is collected via Firebase Cloud Messaging to deliver push notifications (e.g., price alerts, transaction notifications). This token is not linked to your identity.

All collected data is anonymous and cannot be used to identify you personally or access your wallet.

Local Data Storage

All sensitive wallet data is stored locally on your device using platform-native secure storage:

  • Private Keys & Seed Phrases: Encrypted using AES-256 and stored in Android Keystore / iOS Keychain. They never leave your device.
  • Wallet Settings: Network preferences, selected chains, and display settings are stored locally using Hive encrypted storage.
  • Transaction History: Fetched from public blockchain nodes and explorers on demand; not stored on our servers.
  • Biometric Data: Fingerprint/Face authentication is handled entirely by your device's secure hardware. We never access or store biometric data.

Third-Party Services

Light Wallet interacts with the following external services to provide core functionality:

  1. Blockchain RPC Providers (Infura, public nodes): To query blockchain state and broadcast transactions
  2. Block Explorers (Etherscan, Blockchair, etc.): To fetch transaction history
  3. Price APIs (CoinGecko): To display current cryptocurrency prices
  4. Firebase (Google): For anonymous crash reporting, usage analytics, and push notification delivery (Firebase Cloud Messaging)
  5. WalletConnect: For connecting to decentralized applications (DApps)
  6. Rango Exchange / 0x Protocol: For token swap functionality

These services may receive blockchain addresses or transaction data as required for their operation. Please refer to their respective privacy policies for details.
