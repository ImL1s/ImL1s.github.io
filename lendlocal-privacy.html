LendLocal

Privacy Policy

Effective Date: February 20, 2026

Overview

LendLocal is an automated Bitfinex lending tool that runs entirely on your device. You provide your own Bitfinex API keys and the app manages your lending positions on your behalf — locally, with no backend server involved.

We do not collect any personal data. LendLocal has no servers, no accounts, no registration, and no cloud storage. Everything stays on your device.

Information We Collect

LendLocal does not collect, transmit, or store any personal information on external servers. Specifically:

  • No account registration or login is required
  • No name, email address, or contact information is collected
  • No usage analytics or behavioral tracking
  • No crash reporting sent to external services
  • No advertising identifiers or device fingerprinting

API Key Storage

Your Bitfinex API keys are the only sensitive data the app handles. They are stored exclusively on your device using the platform's built-in secure storage:

  • iOS: Stored in the iOS Keychain — Apple's hardware-backed secure enclave
  • Android: Stored in the Android KeyStore — Android's hardware-backed secure credential storage

Your API keys never leave your device. They are never transmitted to our servers (we have no servers), never stored in the cloud, and never shared with any third party.

How the App Communicates

LendLocal communicates directly from your device to Bitfinex's own API using your API credentials. The data flow is:

  • Your Device → Bitfinex API (direct connection)
  • There is no intermediate server or proxy owned by CB Studio

All communication with Bitfinex is encrypted via HTTPS/TLS, consistent with Bitfinex's own security standards. Please review Bitfinex's Privacy Policy for details on how they handle API requests.

Data Stored on Your Device

The app may store the following information locally on your device only:

  • API Keys: Stored in Keychain / KeyStore (encrypted, secure)
  • App Settings & Preferences: Strategy configuration, rate thresholds, and other lending parameters
  • Lending History Cache: Temporary cache of recent lending activity fetched from Bitfinex, used for display purposes only

All of this data remains on your device and can be deleted at any time by uninstalling the app.

Third-Party Services

LendLocal does not integrate with any analytics, advertising, or tracking services. The only external service the app communicates with is:

  • Bitfinex API — to execute lending operations on your behalf using your own credentials

We have no other third-party integrations.

No Analytics or Tracking

LendLocal contains:

  • No analytics SDKs (no Firebase Analytics, no Mixpanel, no Amplitude, etc.)
  • No advertising networks
  • No crash reporting services that transmit data externally
  • No cookies or web tracking of any kind

Children's Privacy

LendLocal is not intended for children under the age of 13. We do not knowingly collect any information from children. As the app requires a Bitfinex account (which itself has age requirements), use by minors is not applicable.

Data Security

Because we collect no data, there is no centralized database to breach. Your API keys are protected by the same hardware-level security that protects your device passwords and banking apps. We strongly recommend:

  • Using a device passcode or biometric lock
  • Creating Bitfinex API keys with only the minimum required permissions (no withdrawal permissions needed)
  • Regularly reviewing your active API keys in your Bitfinex account settings

Changes to This Policy

If we make material changes to this privacy policy, we will update the effective date at the top of this page. We encourage you to review this page periodically. Since we collect no data, changes are unlikely to affect your privacy.
