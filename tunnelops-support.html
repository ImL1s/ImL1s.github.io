常見問題與排除方式

目前能做什麼

搜尋道路隧道目錄、查看可用詳情，並在後端與來源可用時顯示雪山隧道南北向路況、來源健康、資料時效與快取狀態。

目前不能做什麼

不提供導航、背景定位、個人化警示、帳戶同步、訂閱、廣告移除或緊急通報。

為什麼畫面顯示「快取」、「來源降級」或無法取得資料？

App 可能遇到行動網路不穩、Firebase 暫時無法連線、官方資料來源延遲、回應格式無法通過驗證，或目前沒有符合安全時效的資料。 請先確認畫面上的觀測時間與來源狀態，再切換網路並重新開啟 App。不要把 cache 當成最新現場狀況。

Android 快取代表什麼？可以保留多久？

Android 會把最近一次通過結構與環境驗證的公開路況 feed 存在 App 私有空間。遠端更新失敗時，App 可能顯示該 feed 並清楚標示 cache／refresh failure。 從來源最舊觀測時間起超過兩小時後，資料不再符合顯示資格；重新整理時間不會延長這個期限。

為什麼搜尋得到隧道，卻沒有即時路況？

搜尋使用的是較廣的隧道目錄，而目前已實作的官方 live-data scope 僅涵蓋國道 5 號雪山隧道南向與北向；實際可用性仍取決於已設定並部署的後端與來源健康。 搜尋結果可提供名稱、方向與已發布的基本資料，但不代表每座隧道都有車速、車道、排隊或事件資料。

App 會使用我的位置找附近隧道嗎？

不會。目前版本沒有位置 SDK，也不要求精確或背景位置權限。搜尋文字與國家篩選會送到 Firebase Functions 完成目錄查詢， 但 App 不保留搜尋歷史。請勿在搜尋欄輸入姓名、地址或其他個人資料。

如何刪除我的資料或帳戶？

目前版本沒有使用者帳戶，因此沒有雲端帳戶可刪除。若要清除 Android 本機快取，請前往「設定 → 應用程式 → TunnelOps → 儲存空間 → 清除儲存空間」，或解除安裝 App。 若您曾主動寄送支援信，可來信要求查詢或刪除該支援往來；詳見隱私權政策。

為什麼出現驗證、permission denied 或連線錯誤？
  1. 確認網路可正常開啟其他 HTTPS 網站。
  2. 將裝置日期與時間設為自動；錯誤時間可能影響憑證與資料時效判斷。
  3. 完整關閉再重開 App，並確認使用授權的測試版本或正式發行來源。
  4. 若持續發生，回報 App 版本、Android 版本、錯誤畫面與發生時間；請勿寄送任何 token 或憑證。
App 會分析我的使用方式、回報 crash 或顯示廣告嗎？

目前 build 沒有整合 Firebase Analytics、Firebase Crashlytics、廣告 SDK 或付費 SDK。 但 Firebase／Google 基礎設施可能依其政策處理網路與安全中繼資料，且 App Check 會處理 App／裝置完整性訊號。 完整說明請查看隱私權政策。

如何回報疑似錯誤的道路資料？

請寄信並提供：隧道名稱與方向、畫面上的來源觀測時間、資料狀態（remote/cache/降級）、您看到的問題、App／Android 版本，以及可安全分享的截圖。 我們會檢查 App 呈現與資料管道，但無法直接更改官方上游資料。若是正在發生的道路危險，請直接聯絡道路管理機關或緊急服務。

仍需要協助？

主旨使用「TunnelOps Support」。支援信箱會審閱來信，但沒有保證回覆時限，也不是即時監控管道。

Troubleshooting and FAQ

What it does today

Searches a road-tunnel directory, opens available details, and—when the backend and source are available—shows Syueshan Tunnel traffic, source health, freshness, and cache state.

What it does not do

No navigation, background location, personalized alerts, account sync, subscription, ad removal, or emergency reporting.

Why does the App show cache, degraded source, or no data?

Mobile connectivity, Firebase availability, upstream delays, invalid source responses, or the absence of safely eligible data can cause these states. Read the observation time and source status first, then change networks and reopen the App. Never treat cached data as the latest road condition.

What does the Android cache mean, and how long is it valid?

Android stores the most recent public traffic feed that passed structure and environment validation in app-private storage. If remote refresh fails, the App may display it with cache and refresh-failure labels. A feed more than two hours past its oldest source observation is not display-eligible; a new fetch timestamp does not extend that limit.

Why can I find a tunnel with no live traffic?

Search uses a broader tunnel inventory. The currently implemented official live-data scope is limited to northbound and southbound traffic for Taiwan’s Freeway No. 5 Syueshan Tunnel; actual availability still depends on a configured and deployed backend and source health. A search result may provide a name, directions, and published basics without speed, lane, queue, or event data.

Does the App use my location to find nearby tunnels?

No. The current build has no location SDK and requests no precise or background location permission. Search text and country filters go to Firebase Functions for inventory lookup, but the App does not retain a search history. Do not put names, addresses, or other personal information in search.

How do I delete my data or account?

There is no user account in the current build, so there is no cloud account to delete. To remove Android local cache, use Settings → Apps → TunnelOps → Storage → Clear storage, or uninstall the App. If you emailed support, you may ask about or request deletion of that correspondence; see the Privacy Policy.

Why do I see verification, permission-denied, or connection errors?
  1. Confirm the network can open another HTTPS site.
  2. Enable automatic device date and time; incorrect time can affect certificates and freshness checks.
  3. Fully close and reopen the App, and use an authorized test build or official distribution source.
  4. If it continues, report the App version, Android version, error screen, and time. Never send tokens or credentials.
Does the App analyze usage, report crashes, or show ads?

The current build does not integrate Firebase Analytics, Firebase Crashlytics, advertising SDKs, or payment SDKs. Firebase/Google infrastructure may still process network and security metadata under its policies, and App Check processes app/device integrity signals. See the Privacy Policy for the complete boundary.

How should I report road data that looks wrong?

Include the tunnel and direction, source-observation time, state (remote/cache/degraded), what looks wrong, App/Android versions, and a safe screenshot. We can inspect the App and data pipeline but cannot directly change an official upstream record. For an active hazard, contact the road authority or emergency services instead.
