概述

TRON Vault 多簽錢包（以下簡稱「本 App」）是一款非託管 (Non-Custodial) 多簽名錢包應用程式，讓用戶安全管理 TRON 區塊鏈資產。

非託管意味著您完全控制自己的私鑰，我們無法存取、恢復或凍結您的資產。請務必安全備份您的助記詞。

本地數據存儲

所有敏感數據都使用設備原生的安全存儲方式加密存儲在本地：

  • Android：使用 EncryptedSharedPreferences（由 Android Keystore 支持的 AES-256-GCM 加密）
  • iOS：使用 Keychain Services（由 Secure Enclave 硬體支持）

您的私鑰永遠不會以未加密形式存在，也永遠不會傳輸到任何伺服器。

第三方服務

本 App 使用以下第三方服務：

  1. TRON 全節點 API (api.trongrid.io)：查詢區塊鏈公開數據和提交交易
  2. Firebase Analytics / Crashlytics：收集匿名使用統計和崩潰報告
  3. Google AdMob：顯示廣告（收集裝置識別碼用於廣告投放）
  4. WalletConnect：連接第三方 DApp（僅在用戶主動發起時）
  5. App Store / Google Play：處理應用內購買（Pro 訂閱）

各第三方服務的隱私政策請參閱其官方網站。

廣告

本 App 使用 Google AdMob 顯示廣告。AdMob 可能會收集裝置識別碼以提供個性化廣告。您可以在設備設定中選擇退出個性化廣告：

  • Android：設定 → Google → 廣告 → 選擇停用廣告個人化功能
  • iOS：設定 → 隱私權與安全性 → 追蹤 → 關閉「允許 App 要求追蹤」
